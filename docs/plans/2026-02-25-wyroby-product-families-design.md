# Design: Sekcja „Wyroby" — 36 Rodzin Wyrobów CPR 2024

**Data:** 2026-02-25
**Status:** Zatwierdzone przez użytkownika
**Źródło prawne:** Rozporządzenie (UE) 2024/3110 Parlamentu Europejskiego i Rady z dnia 27 listopada 2024 r.

---

## 1. Cel

Zbudować sekcję portalu `/wyroby` z indywidualnymi podstronami dla wszystkich **36 rodzin wyrobów budowlanych** wymienionych w **Załączniku VII** CPR 2024/3110. Każda podstrona (~1000 słów) zawiera:
- Opis rodziny
- Normy zharmonizowane
- Wymagania CPR 2024 (zmiany vs CPR 305/2011)
- System AVS (dawniej AVCP)
- Harmonogram dla tej rodziny
- Checklist producenta
- Linki SEO

**Cel biznesowy:** Portal informacyjny z potencjałem SEO na long-tail keywords. Każda rodzina = osobna fraza kluczowa.

---

## 2. Nomenklatura CPR 2024/3110 (kluczowe zmiany terminologiczne)

| Stary CPR 305/2011 | Nowy CPR 2024/3110 |
|-------------------|-------------------|
| AVCP (Assessment and Verification of Constancy of Performance) | AVS (Assessment and Verification Systems) |
| Deklaracja Właściwości Użytkowych (DoP) | Deklaracja Właściwości Użytkowych i Zgodności (DoP&C) |
| 5 systemów (1+, 1, 2+, 3, 4) | 6 systemów (1+, 1, 2+, **3+** NOWY, 3, 4) |
| Europejska Ocena Techniczna (ETA) | Europejska Ocena Techniczna (ETA) — bez zmian |

**Nowy System 3+** — dedykowany ocenie zrównoważoności środowiskowej (LCA, GWP, EPD). Jednostka notyfikowana wydaje *raport walidacyjny* (nie certyfikat).

## 4. Architektura techniczna

### Nowe pliki

```
content/wyroby/           ← 36 plików .md
src/utils/wyrobLoader.ts  ← loader (wzorzec z blogLoader.ts)
src/pages/Wyroby.tsx      ← katalog /wyroby
src/pages/WyrobDetail.tsx ← detail /wyrob?slug=
```

### Modyfikacje istniejących plików

```
src/user-routes.tsx  ← dodać /wyroby i /wyrob
src/components/Header.tsx ← dodać "Wyroby" do nav
src/pages/App.tsx    ← sekcja "Wyroby budowlane" na homepage
```

### URL struktura

- `/wyroby` — katalog wszystkich 36 rodzin
- `/wyrob?slug=beton` — indywidualna strona rodziny

## 5. UI Design

### `/wyroby` (Wyroby.tsx)
- Hero z tytułem i opisem portalu
- Search bar + filtry kategorii (Konstrukcyjne, Izolacyjne, Przeciwpożarowe, Inne)
- Grid 3 kolumny (desktop) / 2 (tablet) / 1 (mobile) z kartami
- Każda karta: badge numeru rodziny, nazwa PL, system AVS, excerpt, CTA "Czytaj więcej"

### `/wyrob?slug=` (WyrobDetail.tsx)
- Breadcrumb: Strona główna / Wyroby / [Nazwa]
- Sidebar: normy, system AVS, kluczowe daty, related families
- Pełna treść markdown (reaktywna, jak BlogPost.tsx)
- CTA blok do certyfikacji na dole

## 7. Nowe wymogi środowiskowe (charakterystyki horyzontalne - Załącznik X)

Obowiązkowe deklarowanie dla każdej rodziny wyrobów (etapami do 2032):
- GWP (Global Warming Potential) — potencjał globalnego ocieplenia
- ODP (Ozone Depletion Potential)
- AP (Acidification Potential)
- EP (Eutrophication Potential)
- POCP (Photochemical Ozone Creation Potential)
- ADP (Abiotic Depletion Potential)
- WDP (Water Deprivation Potential)
- Zawartość materiałów z recyclingu
- Trwałość i możliwość naprawy
